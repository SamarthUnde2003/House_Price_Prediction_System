# House Price Prediction System

A web-based House Price Prediction System developed using Java, Servlet, JSP, JDBC, and MySQL. The system predicts house prices by implementing a Linear Regression model based on property features such as location, area, and number of rooms.

## Features
- User-friendly interface
- Predict house prices instantly
- Store and manage property data
- Linear Regression based prediction model
- Responsive design using HTML, CSS, and Bootstrap

## Technologies Used
- Java
- Servlet & JSP
- JDBC
- MySQL
- HTML, CSS, Bootstrap
- Linear Regression Algorithm
